Pembayaran di Sesi Ini

    Gunakan QRIS Toko Asli Anda

    Jika Anda sudah memiliki QRIS fisik/merchant resmi (BCA, Mandiri, GoPay, Dana Bisnis, ShopeePay), Anda bisa menampilkan foto QRIS asli Anda di sini agar pelanggan scan langsung lewat aplikasi e-wallet / m-Banking resmi mereka.

    Alur Pencatatan Transaksi Nyata:
    1. Pelanggan scan QRIS asli toko Anda dengan m-Banking / E-wallet.
    2. Uang nyata masuk ke rekening bank / e-wallet toko Anda.
    3. Cek mutasi masuk di HP toko, lalu masukkan nominal di bawah dan klik Catat QRIS Masuk untuk membukukan ke Kas di Bank!

    Panduan Transaksi QRIS

    1. Uji Coba dari Smartphone

    Buka halaman ini dari laptop. Arahkan kamera HP Anda ke QR code di tab Simulator HP; HP akan membuka halaman ini di browser HP. Anda bisa mengetik nominal dan menekan "Bayar", lalu cek web akuntansi Anda — saldo Kas di Bank langsung bertambah secara otomatis!

    2. Transaksi Nyata dengan QRIS Merchant Toko

    Gunakan tab QRIS Toko Asli untuk menampilkan barcode QRIS fisik kedai Anda. Pelanggan mentransfer uang asli melalui BCA/GoPay/Dana Anda. Setelah uang masuk ke rekening, tekan tombol "Catat QRIS Masuk".

    3. Integrasi Payment Gateway Otomatis (Midtrans / Xendit)

    Aplikasi ini sudah memiliki webhook siap pakai di POST /api/qris/webhook. Jika Anda mendaftar di Payment Gateway seperti Midtrans Snap atau Xendit:

    • Set Webhook URL di dashboard Midtrans ke https://domain-anda.com/api/qris/webhook.
    • Set QRIS_WEBHOOK_SECRET di environment variable server (Vercel). Format pesan dan tanda tangan gateway berbeda-beda, jadi perlu satu adapter kecil yang memverifikasi tanda tangan resmi mereka (lihat docs/qris_webhook.md).
    • Setiap ada pembayaran QRIS sukses, uang otomatis tercatat ke Kas di Bank tanpa perlu input manual sama sekali.
